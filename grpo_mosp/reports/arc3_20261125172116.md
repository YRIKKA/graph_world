# ARC-AGI-3 run 20261125172116

## Methods

The pinned Tufa inline runner evaluated the frozen Qwen3.8-27B checkpoint with 4-bit NF4 bitsandbytes weights (run alias `base`, revision `8aa5f05d26b7205477066e1449e0af13f762a299`). Duck used Python tools to inspect the board and action history and submit single or batched moves. The run used medium reasoning effort and played one online pass of SU15 (`su15-1944f8ab`, labeled easy) with one worker. The game opened on the availability check and was used as requested. [Run manifest](../experiment_arc3/runs/20261125172116/manifest.json) · [Game availability](../experiment_arc3/runs/20261125172116/game_availability.json)

The local vLLM 0.33.0 server used a 32,768-token context, disabled prefix caching, and used the PyTorch sampler via `VLLM_USE_FLASHINFER_SAMPLER=0`. The model sampled at temperature 0.6, top-p 0.95, and top-k 20. The evaluator allowed 230 seconds for generation and 240 seconds per client request. The preflight had a 600-second budget, and each level attempt had a two-hour budget with up to two recovery retries per level. [Run manifest](../experiment_arc3/runs/20261125172116/manifest.json) · [vLLM server log](../experiment_arc3/runs/20261125172116/model_server.log)

## Interpreting 2.22% partial RHAE

The **2.22%** is a cumulative game score on a 0–100 scale. Tufa weights SU15's nine levels by their positions, from 1 for level 1 through 9 for level 9, for a total weight of 45. Clearing level 1 in 20 moves against the 22-move human baseline earned full credit for that level. With only level 1 cleared, Tufa caps the game score at `100 × 1/45 = 2.22%`. The move count shows the efficiency of the level-1 solve, and the partial score shows how much of the weighted game the pass cleared. Both passes ended in errors, so the evaluator excluded them from aggregate RHAE.
